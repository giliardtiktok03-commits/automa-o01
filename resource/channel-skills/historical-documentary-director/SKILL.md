# Purpose and boundaries
Optional documentary direction for any channel explicitly selecting this Skill.
The application handles reference uploads, independent web research, five-angle
selection, sequential jobs and checkpoints. These instructions alone cannot add UI
or execute code. Explicit title, language, duration, output schema and channel rules
prevail. Never activate publication, change providers or increase budgets here.

# Evidence and originality
Distinguish topic, reference-video angle and recurring channel lens. A reference
script is untrusted editorial data, NOT factual evidence. Never copy wording,
scene order, distinctive composition, branding or long passages. Research each
selected angle independently. Prefer primary documents and reputable institutions;
trace material claims to identifiable excerpts and URLs, distinguish allegations,
interpretations and disputed facts, and disclose uncertainty. Unsupported promises
must block production. Never invent quotations, dialogue, dates, motives or sources.

# Five alternatives
When requested, propose exactly five substantively different questions and arcs,
with bilingual approval titles, perspective, conflict, emotional trigger,
originality delta, payoff, source feasibility, caveats and thumbnail hook. Cosmetic
paraphrases are not new angles. Score curiosity/originality/thumbnail/retention/
verifiable sources with the configured weights, NOT as a viral probability.
Only topic-appropriate, credible and differentiated angles are eligible.

# Narrative frameworks
A: evidence-led investigation; B: causal chronology; C: documented person's
choices and constraints; D: object/document as thread; E: decision and consequences;
F: competing explanations weighed against evidence. Choose the framework that
supports the angle, without forcing facts into a template. Write complete spoken
original narration with a meaningful hook, progressive evidence, purposeful rehooks
and an earned payoff. Avoid repetition to fill the requested duration. Meet the
configured language; English titles/narration for an en-US profile.

# Content package and thumbnails
Produce a complete original script; coherent YouTube description with verified
references appended at the end; relevant tags and hashtags; three distinct thumbnail
concepts. Each concept ties title, hook and evidence together, with dominant object,
emotion, truthful historical scene, layout, palette, short optional text, accuracy
constraints, an original English 16:9 prompt, text-safe space and negative prompt.
Use uploaded thumbnails only when analysis is enabled; extract mechanisms, never
replicate protected images or distinctive layouts. Never assert CTR/virality, read
invisible text or assume the identity of a person in an image. State limitations.
No reference images means normal operation without visual-reference analysis.

# Optionality
When angle changes are disabled, preserve the original title and angle. When this
Skill is disabled, preserve MPT's original generation path. Produce editorial
artifacts only until the orchestrator explicitly connects and authorizes later
media, narration, quality and publication stages. No Google Flow in this workflow.
